# 🍕 Pizza Sales SQL Analysis

## 📌 Project Overview

This project focuses on analyzing pizza sales data using **MySQL and SQL** to understand sales performance, customer ordering patterns, product performance, and revenue trends.

The project contains **13 SQL analyses** covering order volume, revenue, pizza pricing, pizza size, product popularity, category performance, order timing, daily order quantity, revenue contribution, cumulative revenue, and category-wise top-performing pizzas.

The objective is to apply SQL concepts to a real-world sales dataset and convert raw transactional data into meaningful business insights.

---

## 🎯 Project Objectives

- Analyze the total number of orders
- Calculate total revenue generated from pizza sales
- Identify the highest-priced pizza
- Identify the most commonly ordered pizza size
- Find the top 5 most ordered pizza types
- Analyze total pizza quantity by category
- Analyze order distribution by hour
- Analyze pizza type distribution by category
- Calculate the average number of pizzas ordered per day
- Identify the top 3 pizza types by revenue
- Calculate category-wise contribution to total revenue
- Analyze cumulative revenue over time
- Identify the top 3 pizza types by revenue within each category
